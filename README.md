# 🎲 Sorteio de Cargos

Aplicação web desenvolvida para facilitar o sorteio de cargos entre participantes em atividades da **Ordem DeMolay**. O sistema também pode ser utilizado por outros grupos que precisem distribuir funções por meio de um sorteio.

O projeto surgiu de uma necessidade prática e foi desenvolvido para agilizar a organização de uma atividade, reduzindo a necessidade de realizar o sorteio manualmente.

🔗 **[Acessar a aplicação](https://thiagoono.github.io/Sorteio/)**

## ✨ Funcionalidades

- **Cadastro de participantes:** adicione e edite as pessoas que participarão do sorteio.
- **Cadastro de cargos:** registre e edite os cargos que serão distribuídos.
- **Ordem de sorteio:** defina a ordem em que os cargos serão sorteados.
- **Prevenção de repetições:** participantes já sorteados não são selecionados novamente.
- **Armazenamento local:** os dados são mantidos no armazenamento local do navegador.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilização e apresentação da interface.
- **JavaScript:** lógica e funcionalidades do sistema.
- **LocalStorage:** armazenamento local dos dados no navegador.

## 🚀 Como utilizar

### Acessar online

A maneira mais simples de utilizar o sistema é acessar a versão publicada no GitHub Pages:

**[Abrir Sorteio](https://thiagoono.github.io/Sorteio/)**

### Executar localmente

Como o projeto utiliza HTML, CSS e JavaScript, também é possível executá-lo localmente.

1. Clone o repositório:

   ```bash
   git clone https://github.com/thiagoono/Sorteio.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd Sorteio
   ```

3. Abra o arquivo HTML principal em um navegador.

Não é necessário instalar dependências ou configurar um back-end para executar a aplicação conforme sua estrutura atual.

## ⚠️ Limitações conhecidas

Este projeto foi desenvolvido rapidamente para atender a uma necessidade específica, priorizando a implementação das funcionalidades essenciais para aquela ocasião.

Por esse motivo, existem algumas limitações:

- **Possíveis bugs:** o sistema pode apresentar comportamentos inesperados.
- **Uso recorrente limitado:** a aplicação não foi planejada inicialmente para facilitar a realização de múltiplos sorteios independentes.
- **Sem exportação de resultados:** não existe uma funcionalidade para exportar ou baixar o resultado do sorteio.

O projeto representa uma solução prática para um problema real e também uma oportunidade de identificar melhorias para futuras versões.
